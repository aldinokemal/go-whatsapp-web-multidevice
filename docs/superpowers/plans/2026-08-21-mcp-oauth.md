# Embedded MCP OAuth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in embedded OAuth 2.1 authorization server for `/mcp` with Claude DCR compatibility and Basic Auth fallback.

**Architecture:** Keep OAuth transport/security logic in `src/ui/mcp/oauth`, backed by a dedicated SQLite store using `pkg/sqlite`. Wire public OAuth routes and a hybrid Basic/Bearer MCP middleware into `cmd/rest.go` before the existing global Basic Auth middleware; leave all other REST/UI authentication unchanged.

**Tech Stack:** Go 1.25.5, Fiber v3, database/sql, existing CGO/pure-Go SQLite driver abstraction, mcp-go streamable HTTP.

**Spec:** `docs/superpowers/specs/2026-08-21-mcp-oauth-design.md`

## Global Constraints

- OAuth is opt-in and defaults off.
- No new Go dependency and no external IdP.
- DCR is compatibility-only; do not advertise CIMD until implemented.
- PKCE S256, exact redirect matching, RFC 8707 resource binding, RFC 9207 `iss`, hashed opaque tokens, and refresh reuse family revocation are required.
- OAuth-enabled `/mcp` must continue accepting current Basic Auth credentials.
- OAuth-disabled behavior must remain unchanged.
